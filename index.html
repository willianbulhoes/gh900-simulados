Como usar

  1. Acesse uma prova e comece o teste. O cronômetro de 90 minutos inicia automaticamente.
  2. Responda as questões e clique Enviar prova. O resultado e as explicações aparecem na página.
  3. Para ver o gabarito completo sem fazer a prova, use os links de gabarito.

Hospedar no GitHub Pages

  1. Crie um repositório no GitHub (ex.: gh900-simulados).
  2. Envie todos os arquivos desta pasta para o repositório.
  3. No GitHub, vá em Settings → Pages e selecione Source: Deploy from a branch, Branch: main e Folder: /root.
  4. Salve. Após alguns minutos, seu site estará disponível em https://SEU-USUÁRIO.github.io/gh900-simulados/.
